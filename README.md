# 차량 피하기 게임 (Vehicle Dodge)

## 프로젝트 소개

Unity 6을 이용하여 제작한 차량 피하기 게임입니다.

플레이어는 중앙 공간에서 이동하며 상하좌우 네 방향에서 다가오는 차량을 피해야 합니다. 제한 시간인 60초 동안 생존하면 게임을 클리어할 수 있으며, 차량과 충돌하여 목숨이 모두 소진되면 게임 오버가 됩니다.

기존 좌우 방향의 차량 이동 시스템을 확장하여 상하좌우 네 방향에서 차량이 접근하도록 구현했으며, 플레이어가 위기 상황에서 빠르게 이동할 수 있도록 대시 기능을 추가했습니다.

게임 진행 시간에 따라 차량의 이동 속도가 점진적으로 증가하여 난이도가 상승하도록 구현했습니다.

또한 게임 설정을 JSON으로 관리하고 HTTPS 서버와 연동하여 외부 설정을 불러올 수 있도록 구현했습니다.

---

## 조작 방법

- **W** : 위쪽 이동
- **A** : 왼쪽 이동
- **S** : 아래쪽 이동
- **D** : 오른쪽 이동
- **Space** : 대시
- **모바일** : 화면 터치 버튼을 이용한 이동

---

## 게임 규칙

- 플레이어의 기본 목숨은 3개입니다.
- 차량과 충돌하면 목숨이 1 감소합니다.
- 충돌 후 3초 동안 무적 상태가 적용됩니다.
- 무적 상태에서는 플레이어가 깜빡이는 효과가 나타납니다.
- 목숨이 모두 소진되면 게임 오버가 됩니다.
- 60초 동안 생존하면 게임 클리어가 됩니다.
- 게임 진행 시간에 따라 차량의 속도가 증가합니다.
- 대시를 사용하면 짧은 시간 동안 이동 속도가 증가합니다.
- 대시 사용 후 재사용 대기시간이 적용됩니다.
- 대시 중에는 별도의 무적 효과가 적용되지 않습니다.

## 구현 기능

### 1. 플레이어 이동 및 대시 시스템

- CharacterController를 사용한 플레이어 이동 구현
- WASD 키보드 입력을 통한 이동 제어
- Unity Input System을 이용한 키보드 입력 처리
- 모바일 터치 버튼을 이용한 이동 지원
- Space 키를 이용한 대시 기능 구현
- 마지막 이동 방향을 기준으로 대시 방향 설정
- 대시 지속 시간 및 재사용 대기시간 설정
- 대시 중에도 차량 충돌 판정 유지

### 2. 4방향 차량 시스템

- 상하좌우 네 방향의 차량 이동 구현
- 방향별 차량 이동 스크립트 분리
- 총 16대의 차량 배치 및 자동 이동
- 차량별 이동 속도 설정
- 이동 경계 도달 시 반대편 위치로 재배치
- 게임 재시작 시 차량 위치 초기화
- 게임 진행 시간에 따른 차량 속도 증가
- 속도 증가 시 `SPEED UP!` 알림 표시

### 3. 충돌 시스템

- Trigger Collider를 이용한 충돌 감지
- 차량 충돌 시 목숨 감소
- 충돌 시 피격 파티클 이펙트 생성
- 충돌 후 3초 무적 상태 적용
- 무적 상태에서 플레이어 깜빡임 효과 구현
- 대시 중에도 기존 충돌 시스템 유지

### 4. UI 시스템

- 시작 화면 및 게임 시작 기능
- 남은 목숨 표시
- 남은 시간 표시
- 속도 증가 알림 표시
- 게임 오버 화면 표시
- 게임 클리어 화면 표시
- 게임 재시작 기능
- 모바일 방향 조작 버튼 배치

### 5. 게임 진행 및 재시작

- 60초 카운트다운 타이머
- 목숨 소진 시 게임 오버 및 게임 정지
- 60초 생존 시 게임 클리어 및 게임 정지
- 재시작 시 플레이어와 차량 위치 초기화
- 재시작 시 목숨, 시간, 차량 속도 초기화
- 대시 상태 및 재사용 대기시간 초기화

### 6. 게임 데이터 저장

- PlayerPrefs를 이용한 게임 기록 저장
- 총 게임 횟수 저장
- 총 클리어 횟수 저장
- 마지막 클리어 시 남은 목숨 저장
- 앱 일시정지 및 종료 시 데이터 저장

### 7. 사운드 및 이펙트

- 버튼 클릭 사운드
- 차량 충돌 사운드
- 게임 오버 사운드
- 게임 클리어 사운드
- 충돌 시 Particle System을 이용한 이펙트 생성
- 플레이어 식별을 위한 시각적 표시 추가

### 8. JSON 설정 시스템

- JSON 파일을 이용한 게임 설정 관리
- 플레이어 이동 속도 설정
- 게임 제한 시간 설정
- 차량 속도 증가 간격 및 증가량 설정
- 차량 최대 속도 배율 설정
- JSON 설정값을 게임에 적용

### 9. HTTPS 서버 연동

- ASP.NET Core 기반 콘텐츠 서버 구축
- HTTPS를 이용한 외부 JSON 파일 요청
- UnityWebRequest를 이용한 서버 데이터 수신
- 서버 접속 실패 시 로컬 JSON 파일 사용
- 서버 및 로컬 JSON 모두 실패할 경우 기본 설정값 적용

### 10. Addressables 리소스 관리

- Addressables 패키지를 이용한 리소스 관리
- 테스트 Prefab 비동기 로드
- 로드 재시도 기능 구현
- 로드된 리소스 해제 기능 구현
- Editor 환경에서 리소스 로드 및 해제 동작 확인

### 11. Profiler 및 코드 정리

- Unity Profiler를 이용한 CPU 사용량 측정
- Memory 모듈을 이용한 메모리 사용량 확인
- 차량 이동 스크립트의 Transform 캐싱 적용
- 차량 이동 및 위치 초기화 기능 유지
- 기존 기능을 유지하면서 스크립트 구조 정리

## 프로젝트 마무리

본 프로젝트를 통해 Unity를 이용한 기본적인 게임 플레이 시스템 구현부터 플레이어 이동, 대시, 4방향 차량 이동, 충돌 처리, UI, 데이터 저장 및 외부 서버 연동까지 다양한 기능을 경험했습니다.

특히 기존 좌우 방향의 차량 피하기 게임을 상하좌우 네 방향으로 확장하면서 여러 방향의 오브젝트 이동과 위치 초기화 시스템을 구현했습니다. 또한 대시 기능을 추가하여 플레이어의 이동 방식과 게임 플레이 요소를 확장했습니다.

이외에도 JSON을 활용한 게임 설정 관리, HTTPS 서버 연동, Addressables를 이용한 비동기 리소스 관리 및 Unity Profiler를 통한 성능 분석을 진행하며 게임 개발 전반의 작업 과정을 경험했습니다.
